ADVISION — PROFESSIONAL EDITION

Ishga tushirish:
1. ZIP faylni kompyuterga yuklab oling va Extract All qiling.
2. Chiqqan AdVision_Professional papkasini VS Code orqali Open Folder qiling.
3. index.html faylini oching.
4. VS Code'da Go Live tugmasini bosing (Live Server kengaytmasi o'rnatilgan bo'lishi kerak).
5. Internet yoqilgan bo'lsin: maqola muqova rasmlari Unsplash rasmlaridan yuklanadi.

Fayllar:
- index.html: bosh sahifa
- style.css: barcha sahifalarning dizayni
- data.js: boshlang'ich maqolalar va localStorage funksiyalari
- script.js: qidiruv, kategoriya va maqola kartalari
- article.html / article.js: alohida maqola sahifasi
- admin.html / admin.js: maqola boshqaruv paneli

Admin panelda maqola qo'shishda muqova rasmi uchun to'g'ridan-to'g'ri rasm URL manzilini kiriting.
Mavjud 12 maqola uchun rasm manzillari qo'shilgan.

MUHIM:
Bu versiya front-end prototipidir. Admin ma'lumotlari localStorage'da faqat shu brauzerda saqlanadi. Bir nechta qurilmada umumiy kontent, haqiqiy admin autentifikatsiyasi va server ma'lumotlar bazasi uchun backend kerak bo'ladi.
Reklama bloklari hozircha joy ajratilgan namunaviy maydonlar, daromad keltirmaydi. Haqiqiy reklama uchun reklama tarmog'i tasdiqlashi va uning rasmiy kodi kerak.
